Amazon Clone Website 🛒

A simple and responsive Amazon Clone website built using HTML and CSS. This project was created to practice front-end web development concepts like layout designing, Flexbox, CSS styling, navigation bars, hero sections, product cards, and responsive web design.

🚀 Features
Amazon-style navigation bar
Search bar design
Hero banner section
Product cards with images
Footer section
Responsive layout using CSS
Clean and beginner-friendly code

🛠️ Technologies Used
HTML5
CSS3
